What is OneSearch?

OneSearch is a keyword intelligence framework that unifies a brand's full search presence — SEO and SEM — into a single masterlist, then renders it as an interactive HTML dashboard. It answers one central question: for every keyword that matters, how much of the available search demand are we actually capturing?

Pipeline — Step by Step

1

Normalize all sources

Each source is read and cleaned independently: number formats standardized (French vs English), column names unified, rows without keywords dropped. GSC and SQR both handle comparison-mode exports with two periods side by side.

ingest.norm_gsc()  ·  norm_sqr()  ·  norm_se()  ·  norm_ks()
2

Merge GSC + SQR → unified keyword spine

Full outer join on keyword text. Keywords with ≤ 1 click in both periods are dropped (noise filter). Result: ~3,663 unique keywords, each with SEO and/or SEM data. This is the spine everything else attaches to.

merge.merge_gsc_sqr()  ·  format_rows.format_base_rows()
3

Build trigram (n-gram) index

Every keyword in the spine is broken into overlapping 3-character fragments (trigrams). A Jaccard similarity index is built on these fragments — built once, reused for all subsequent matching steps. This allows fuzzy matching: "greek yogurt" matches "yogurt greek", "greek yoghurt", "high protein greek yogurt".

trigram.build_index()  ·  threshold: ≥ 0.50 for SE Ranking, ≥ 0.65 for Keyword Study auto-write
4

Match SE Ranking data

1,240 SE Ranking keywords are matched against the spine. Each match attaches organic position, search volume, CPC and search intent to the keyword row.

match_se.match_se_keywords()  ·  709 matches for Oikos USA
5

Match Keyword Study taxonomy

14,273 Keyword Study entries are matched against the same trigram index. Similarity ≥ 0.65: auto-written to masterlist (Topics, Category, Sub-Category, 13 tag columns, 6 monthly volume columns). Similarity 0.50–0.65: sent to a KW Review tab for human approval.

match_ks.match_ks_keywords()  ·  956 auto-matched · borderline flagged for review
6

Join GA4 conversions

MikMak conversion events (Checkout + Offline Store) are matched to keywords via their SE Ranking landing page URL. When multiple keywords share a URL, conversions are split pro-rata by each keyword's Q1 SEO click share.

Writes: Conversions SEO Q1 2026 (MM Checkout) · Conversions SEM Q1 2026 (MM Offline Store)
7

Write masterlist + post-enrichment

All 3,663 rows × 57 columns are written to Google Sheets in batched API calls. ARRAYFORMULA cells (coverage ratios, estimated SEO cost) are written separately. After the main write, the SE Ranking API fills any remaining blank search volume cells.

Run: python3 run_onesearch.py  ·  ~8 minutes total  ·  zero LLM tokens
8

Build HTML dashboard

A separate script reads the completed masterlist, injects all data into a reference HTML template, applies brand-specific config (colors, regex, territory topics), generates the Territory Deep Dive and Recommendations panels, and writes a single self-contained HTML file.

Run: python3 build_html_oikos.py  ·  ~45 seconds  ·  zero LLM tokens

Benefits of This Approach

🖥️

Runs locally — no infrastructure

Both scripts run in a terminal on a standard laptop. No server, no cloud function, no subscriptions. One .env file with credentials is all the setup needed.

💰

Near-zero cost per run

Core pipeline makes zero LLM API calls. Only Google Sheets API (free) and SE Ranking API (minimal). A full end-to-end run costs under $0.10 in API fees.

🔁

Deterministic — same data, same output

No prompt-to-prompt variation. The same masterlist always produces the same HTML. Every rebuild is identical. If something looks wrong, the cause is always in the data or the script.

⚡

Fast

8 minutes to populate a 3,600-row masterlist from scratch. 45 seconds to build the interactive HTML dashboard. A full refresh after new data takes under 10 minutes total.

📋

Replicable across clients

New client = duplicate the build script, update 12 lines of config (Sheet IDs, brand colors, period labels). The brand-detection regex loads automatically from a reference sheet.

🎯

Analyst time goes to insight

Data assembly is fully automated. The dashboard opens ready for annotation — editable commentary boxes, JSON export/import, action card placeholders all built in.
