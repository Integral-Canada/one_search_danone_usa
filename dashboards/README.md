# dashboards/

HTML dashboard files — the visual output of the OneSearch pipeline. Open in any browser to explore keyword performance.

| File | Client |
|---|---|
| `oikos-usa/oikos-usa_onesearch_dashboard.html` | Oikos USA |
| `silk/silk_onesearch_dashboard.html` | Silk USA |
| `international-delight/international-delight_onesearch_dashboard.html` | International Delight USA |

Canadian market examples (Activia CA) are in `examples/`.

Dashboards are generated by `build_dashboard.py --brand <handle>` (current entry point, since the 2026-06-18 multi-brand rewrite — see the repo root README). It runs `scripts/build_html.py`, which patches `scripts/build_html_oikos.py`'s module-level globals from `brands/<handle>/config.json` at runtime and writes the output to `dashboards/<handle>/<handle>_onesearch_dashboard.html`. Do not edit `scripts/build_html_oikos.py`'s hardcoded source-data references directly — everything brand-specific comes from config.
