# dashboards/

HTML dashboard files — the visual output of the OneSearch pipeline. Open in any browser to explore keyword performance.

| File | Client |
|---|---|
| `oikos_usa_onesearch_dashboard.html` | Oikos USA |

Canadian market examples (Activia CA) are in `examples/`.

Dashboards are generated by `scripts/build_html_oikos.py`. To rebuild after a pipeline run, update the source data reference in that script and re-run it.
