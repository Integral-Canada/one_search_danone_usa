# skill/

OneSearch skill definition — used by the Claude Code AI assistant to understand and run the pipeline interactively.

| File | What it is |
|---|---|
| `workflow.md` | Step-by-step workflow the skill follows |
| `workflow_v6.json` | Versioned workflow definition (machine-readable) |
| `references.md` | Reference material the skill draws on |
| `PLAN.md` | Development plan for the skill |

These files are not part of the Python pipeline. They are only relevant if you are using Claude Code to assist with OneSearch tasks.
