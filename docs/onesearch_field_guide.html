OneSearch Field Guide

A unified SEO + SEM keyword masterlist, built from five Google Sheets and one Python pipeline. This page is everything a teammate needs to run it for a brand they've never touched.

Repo: one_search_danone_usa Entry points: run_pipeline.py · build_dashboard.py Install: none — stdlib only

What it does

For every keyword driving traffic to a brand's site — organic or paid — OneSearch answers one question: what does the full picture look like? It pulls Search Console, Google Ads search terms, SE Ranking, an internal keyword study, and GA4 conversions, fuzzy-matches them onto one keyword spine, and writes a single enriched masterlist back to Sheets. A dashboard script then turns that masterlist into a shareable HTML report.

Before you run it

Access
Edit rights on the brand's Masterlist, source-config, and export sheets — same Google account the pipeline's OAuth token was issued for.
Credentials
A .env file in the repo root with GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, GOOGLE_REFRESH_TOKEN. Ask whoever set up the last brand for a copy — it's shared per-team, not per-person.
Brand config
A brands/<handle>/config.json already exists — see "Adding a new brand" if it doesn't yet.
Python
Python 3, nothing else. No pip install, no virtualenv — the pipeline is standard-library only.

Run it

# build the masterlist for a brand python3 run_pipeline.py --brand oikos-usa # then build the HTML dashboard from it python3 build_dashboard.py --brand oikos-usa

Swap oikos-usa for any handle under brands/. First time on a brand, run with --max-rows 500 to sanity-check in under a minute before committing to a full run — a full masterlist can take several minutes and rewrites the whole sheet.

python3 run_pipeline.py --brand oikos-usa --max-rows 500

Adding a new brand

1

Register the exports

In the shared source-config sheet, tab One Search, add a row block for the brand: GSC Export, Account Level SQR Report, SE Ranking, Keyword study, plus the two GA4 conversion exports. Each row needs a real Doc ID and tab name — a blank or TBD cell will hard-stop the run.

2

Create brands/<handle>/config.json

Copy an existing brand's config as a starting point. Set client_name, lang, the period block (your two comparison quarters — labels must match the GSC export's column headers exactly), and the sheets block (Masterlist ID + tab).

3

Prep the destination Masterlist

Row 1 needs the full column header set, with period labels matching config.json exactly (e.g. rename every stale period header to your brand's actual comparison period). The script reads column order from this row — it won't reorder or rename anything for you.

4

Dry-run, then commit

Run with --max-rows 500 first and read the terminal summary — row counts per source, match rates, anything sent to review. Once it looks right, run the full pipeline, then build_dashboard.py.

Reading the output

TabWhat lands there
ListingThe masterlist itself — one row per keyword, ~58 columns of SEO, SEM, volume, cost, and taxonomy data.
5 < Cos < 0.65Borderline keyword-study matches. Mark approved = YES (optionally correct manual_ks_match) and re-run to fold them into the masterlist.
Cos < .5Unmatched keywords — no confident pairing was found. Same review-and-approve flow as above.

A blank cell in the masterlist almost always means one source export is missing or a period label doesn't line up — it's rarely the matching logic. Check the troubleshooting table below before assuming the data itself is at fault.

When it won't run

!

The pipeline hard-stops rather than guessing. A missing source or a mismatched label produces an immediate ERROR: '...' not found in source config sheet — not a partial, best-effort masterlist.

SymptomLikely causeFix
ERROR: 'X' not found in source config sheetThat export's row is missing, or its label doesn't match exactly (e.g. Account Level SQR Report vs. ..._Q1/..._Q2)Add or rename the row in the One Search tab so the label matches what run_pipeline.py requires. If Ads only exports one period at a time, merge the two per-period tabs into a single tab with Clicks/Clicks (Compare to) style columns first.
ERROR: required column '...' not found in Masterlist headersRow 1 of the destination sheet doesn't have a header matching the brand's period labelsRename the header cells to match config.json's period.p1_label / p2_label exactly.
Whole columns blank (volume, monthly search)The keyword study export doesn't include the expected Searches: <Month> <Year> columns for the current periodRe-export the keyword study with monthly columns covering both comparison periods. Month labels use 3-letter abbreviations (Apr, Jun) — spelled-out month names won't match.
SEM comparison-period columns all zeroThe Ads search-term report was only exported for one periodRe-export with the comparison period selected, or merge two separate per-period tabs into one before registering it.
Position / CPC / intent columns sparseNo SE Ranking export registeredPosition falls back to GSC's average automatically; CPC and intent have no fallback — add an SE Ranking export to fill them.
