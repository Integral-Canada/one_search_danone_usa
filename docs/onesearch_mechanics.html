What it is

The Masterlist is one row per keyword, unifying organic (SEO) and paid (SEM) performance for that keyword — built by pulling five Google Sheets, matching them onto a shared keyword list, and merging the results. Everything below happens in a fixed order; later steps depend on earlier ones.

Hardcoded vs. config-driven

Rule of thumb: blank column or data in the wrong period → check config.json first. Still wrong after that → it's a code question, not a data question.

✏️ config.json — edit it yourself
  • Period labels — p1_label / p2_label, GSC date prefixes
  • Taxonomy dimension names — what AL–AY are actually called for this brand
  • Competitor blocklist, coverage targets
  • Which sheet tabs each export/Masterlist lives in
🔧 code — ask Claude
  • Match-confidence thresholds (0.50 / 0.60 / 0.65)
  • Adding a genuinely new data source to the pipeline
  • The dashboard's HTML/CSS template itself
  • Anything in a file marked deprecated — don't run these, ask instead

Before you run it

Every required export is registered under the brand's own tab in the source-config sheet — not a shared tab with other brands
The Masterlist's header row period labels match config.json's p1_label/p2_label exactly
The Keyword Study export has the columns the pipeline expects (Keyword, TOPIC/CATEGORY, monthly Searches: <Month> <Year> columns)
The Ads search-term report covers both comparison periods (or is merged into one if it was pulled as two separate exports)

What it is

The dashboard is a static HTML report built from a finished Masterlist — it never touches raw source data. It's the client-facing deliverable: an interactive table, territory breakdowns, and coverage stats, all baked into one file.
